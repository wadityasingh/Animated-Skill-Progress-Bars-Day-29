Architecture & Core Concepts

Technical Notes & Interview Insights

Practical engineering answers exploring how progress bar animations, scroll intersection triggers, and configurable attributes are architected under the hood. Click any card to expand.

To animate a bar filling smoothly, construct an outer container element (.progress-track) with a fixed height and overflow: hidden. Inside it, place an inner fill element (.progress-fill) initialized to width: 0%. Apply a CSS transition on the width property with an ease-out timing curve. When triggered, JavaScript updates the element's inline style (e.g., bar.style.width = target + '%'). The browser’s layout engine then smoothly interpolates the width from 0% to the target percentage without stutter. 

/* CSS */
.progress-fill {
  width: 0%;
  height: 100%;
  transition: width 1.25s cubic-bezier(0.22, 1, 0.36, 1);
}

// JavaScript
const target = bar.getAttribute('data-progress'); // e.g. "90"
bar.style.width = `${target}%`;

IntersectionObserver is a high-performance browser API that asynchronously detects when a DOM element enters or exits the viewport (or a specified scrollable ancestor container).

Unlike traditional window.addEventListener('scroll', ...) listeners paired with getBoundingClientRect()—which fire on the main thread and frequently cause layout thrashing and dropped frames—IntersectionObserver runs off-thread. In this portfolio, it watches the skills section with a threshold: 0.18, animates the progress bars only when visible to the visitor, and immediately calls observer.unobserve(entry.target) so the animation doesn't repeat unintentionally on normal scrolling. 

const observer = new IntersectionObserver((entries, obs) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      animateAllBars();
      obs.unobserve(entry.target); // Unobserve to prevent unwanted re-runs
    }
  });
}, { threshold: 0.18 });

observer.observe(document.getElementById('skills'));

Percentages are kept configurable by storing each skill's target percentage directly in an HTML5 data attribute (such as data-progress="90") on each progress bar element.

The JavaScript code queries all .progress-fill elements in a single reusable function, reads their bar.getAttribute('data-progress') value, clamps it between 0 and 100, and assigns it to style.width. This decouples the visual styling and logic from the data—meaning skills can be added, removed, or have their percentages adjusted directly in the HTML without modifying any CSS or JavaScript files. 

<!-- Fully configurable in HTML markup -->
<div class="progress-fill" data-progress="90"></div>
<div class="progress-fill" data-progress="85"></div>

// JavaScript reads dynamically
const percentage = parseInt(bar.getAttribute('data-progress'), 10);
bar.style.width = `${percentage}%`;
